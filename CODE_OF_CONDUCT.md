# Code Of Conduct

YubiWatch should be a calm, respectful project space.

## Standards

Expected behavior:

- Be respectful and direct.
- Assume good intent, especially when reviewing security-sensitive code.
- Give feedback about code and behavior, not personal traits.
- Keep discussions focused on making the project safer, clearer, and easier to maintain.
- Be patient with people learning Rust, Windows APIs, or security concepts.

Unacceptable behavior:

- Harassment, threats, or personal attacks.
- Dismissive comments about someone’s experience level.
- Sharing private information without consent.
- Encouraging unsafe security practices without clear warnings.
- Repeatedly derailing technical discussions.

## Enforcement

Maintainers may remove comments, close issues, block contributors, or decline contributions that violate this code.

## Reporting

For now, report issues privately to the repository owner or maintainer. If this project becomes public or multi-maintainer, add a dedicated reporting contact here.
