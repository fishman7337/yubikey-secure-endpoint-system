# Maintainers

## Current Maintainer

## Maintainer Duties

- Review security-sensitive changes.
- Keep recovery paths documented.
- Run release checks before publishing builds.
- Keep dependencies minimal.
- Keep the dashboard local-only.

## Becoming A Maintainer

For now this is an owner-led project. If the project becomes public or receives regular contributions, add criteria here for maintainer nomination, review expectations, and release permissions.
